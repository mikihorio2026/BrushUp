# 制作アプリのタイトル
今日は鍋にしようアプリ

## 制作アプリの説明（40文字程度）
冷蔵庫をあけて
そこにある食材で
どんな鍋が作れるかな？

## 工夫した点、こだわった点
- より実際の生活に寄せて、食材を好きなだけ選べるようにした。（前回は1種類ずつしか選べなかった
- 選んだ食材を最大限に活かした場合どの鍋がよいかをマッチング
- マッチング上位3位を表示して選べるようにした（前回はランダム表示
- この鍋にはこれがないと成り立たない食材（必須食材）とあったらいいよね食材を分けて登録し、必須食材のほうがマッチング点数が高くなるよう設定した
- これまたより実際の生活に寄せて、冷蔵庫の中から使える食材と、買ってきてほしい食材を表示
